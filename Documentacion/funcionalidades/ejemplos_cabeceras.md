# Ejemplos Prácticos - Cabeceras Empresariales COBOL

## Introducción

Este documento presenta ejemplos prácticos de cómo la funcionalidad de **Cabeceras Empresariales** genera automáticamente cabeceras COBOL estandarizadas para diferentes tipos de programas y contextos empresariales.

## Patrones de Reconocimiento

### Extracción de Nombres de Programa

#### Patrones Soportados
1. **"programa XXXX"**: `"Crear programa SUPPGPR1 para..."`
2. **"PROGRAM-ID XXXX"**: `"Desarrollar PROGRAM-ID CTABANK1..."`
3. **"llamado XXXX"**: `"Sistema llamado EMPGEST1 que..."`
4. **"nombre XXXX"**: `"Programa con nombre INVCTRL1..."`

#### Ejemplos de Extracción
```
Entrada: "Crear programa SUPPGPR1 para proveedores"
Extraído: SUPPGPR1

Entrada: "Desarrollar PROGRAM-ID CTABANK1 bancario"
Extraído: CTABANK1

Entrada: "Sistema llamado EMPGEST1 para empleados"
Extraído: EMPGEST1

Entrada: "Programa con nombre INVCTRL1 de inventario"
Extraído: INVCTRL1
```

### Inferencia de Sistemas

#### Palabras Clave por Sistema
```
BANCARIO: banco, cuenta, transaccion, credito, debito, deposito
SUMINISTROS: proveedor, compra, suministro, orden, pedido
RECURSOS HUMANOS: empleado, nomina, personal, trabajador
CONTABILIDAD: contable, financiero, balance, asiento
VENTAS: cliente, venta, factura, producto, comercial
INVENTARIO: stock, almacen, producto, existencia
```

#### Ejemplos de Inferencia
```
"gestionar cuentas bancarias" → BANCARIO
"administrar proveedores" → SUMINISTROS  
"calcular nómina empleados" → RECURSOS HUMANOS
"generar balance contable" → CONTABILIDAD
"facturar clientes" → VENTAS
"controlar stock almacén" → INVENTARIO
```

### Mapeo de Subsistemas

#### Por Prefijo de Programa
```
SUP* → GESTION DE PROVEEDORES
EMP* → GESTION DE EMPLEADOS
CLI* → GESTION DE CLIENTES
INV* → CONTROL DE INVENTARIO
CTA* → GESTION DE CUENTAS
TRX* → PROCESAMIENTO DE TRANSACCIONES
```

#### Ejemplos de Mapeo

## Casos Especiales

### Programa Sin Nombre Específico
**Solicitud:**
```
"Crear un programa para calcular intereses"
```

**Resultado:**
- **PROGRAM-ID**: PROG001 (por defecto)
- **SISTEMA**: BANCARIO (inferido de "intereses")
- **SUBSISTEMA**: GENERAL (por defecto)

### Múltiples Sistemas en Contexto
**Solicitud:**
```
"Programa bancario para gestionar cuentas de empleados"
```

**Resultado:**
- **SISTEMA**: BANCARIO (primera coincidencia)

## Mejores Prácticas

### Para Usuarios
1. **Especificar nombre del programa** claramente en la solicitud
2. **Incluir contexto del dominio** (bancario, suministros, etc.)
3. **Describir objetivos** específicos del programa
4. **Usar terminología estándar** del dominio empresarial

### Para Desarrolladores
1. **Mantener patrones actualizados** según nuevos casos
2. **Validar inferencias** con tests exhaustivos
3. **Documentar nuevos sistemas** y subsistemas
4. **Monitorear precisión** de la inferencia automática

## Troubleshooting

### Problemas Comunes

#### Sistema No Reconocido
**Síntoma**: Sistema aparece como "GENERAL"
**Solución**: Agregar palabras clave específicas del dominio

#### Programa No Extraído
**Síntoma**: PROGRAM-ID aparece como "PROG001"
**Solución**: Usar patrones reconocidos para especificar nombre

#### Subsistema Incorrecto
**Síntoma**: Subsistema no coincide con expectativa
**Solución**: Verificar mapeo de prefijos de programa
